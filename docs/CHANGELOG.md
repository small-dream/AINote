# 更新日志

## v0.9.0 — 2026-09-01

### 应用图标

- 重新设计应用图标：采用简约扁平风格，品牌蓝纯色圆角方底 + 白色几何 `N` 字标，移除原有的 Git 分支元素。
- 同步更新 Windows、macOS、iOS、Android 各平台全套图标。

## v0.8.0 — 2026-09-01

### 富文本代码块语言选择

- 代码块头部内嵌语言下拉（参考 Typora/Notion），点击即可从 37 种常见语言中选择，也可切回「自动检测」。
- 语言切换即时生效并随笔记保存，Markdown 互转时保留所选语言，兼容 `ts`、`js` 等常见别名。

## v0.7.0 — 2026-09-01

### 富文本代码块语法高亮

- 富文本编辑器代码块接入 Lowlight（highlight.js）语法高亮，支持 37 种常见语言。
- 指定语言（如 ` ```ts `）按语言着色，未指定语言时自动检测。
- 代码块顶部显示语言徽标，配色与 Markdown 预览共用同一套语义色并随主题切换。

## v0.6.4 — 2026-09-01

### 缺陷修复

- 笔记列表和目录树隐藏 `.md` / `.ainote` 后缀。
- 恢复 Markdown 笔记的 `M` 图标，富文本笔记使用独立图标。
- 修复富文本笔记打开后内容丢失的问题。

## v0.6.3 — 2026-09-01

### 发布修复

- 补齐保存失败重试文案和 Rust 锁定版本，确保发布构建与本地版本一致。

## v0.6.2 — 2026-09-01

### 编辑体验优化

- 自动保存改为停止输入 3 秒后写入本地文件。
- 工作区空闲 15 分钟后批量生成 `note: auto commit`。
- 移除编辑器常驻保存按钮，保留 Cmd/Ctrl+S 快捷保存与失败重试。
- 笔记列表和详情隐藏 `.md` / `.ainote` 后缀；富文本笔记使用独立图标。

## v0.6.1 — 2026-09-01

### 富文本与 Markdown 互转

- 新增「一键转换笔记类型」：富文本工具栏「转换为 Markdown」、Markdown 顶部栏「转换为富文本」，转换后自动提交 Git 并打开新类型笔记。
- 转换走原子命令（`convert_note`）：写新扩展名文件后删除旧文件；内容由前端即时生成（富文本经 `tiptap-markdown`，Markdown 经 TipTap 解析）。
- 新增转换纯函数测试与 Rust 转换仓库测试。

## v0.6.0 — 2026-09-01

### 真富文本编辑（.ainote）

- 新增「真富文本」笔记类型：新建时可选 Markdown / 富文本，富文本以 TipTap JSON（`.ainote`）存储并走 Git 版本化。
- 富文本所见即所得编辑器：标题、加粗、斜体、删除线、行内代码、引用、无序/有序/任务列表、代码块、分割线。
- 图片导入到仓库 `assets/`，存仓库相对路径，跨设备可移植；3×3 表格插入、列宽拖拽与删除表格。
- `[[双链]]` 与 `#标签` 可视化 mark，渲染为可点击元素：双链跳转目标笔记，标签跳转侧边栏标签索引。
- 斜杠命令 `/`：输入弹出命令菜单，支持标题/列表/任务/引用/代码块/表格/分割线/行内格式，键盘上下选择、回车执行。
- 选中文本气泡菜单：块级与行级格式一键切换。
- Markdown 互转导出：富文本内容可复制为 Markdown / 粘贴 Markdown 导入（`tiptap-markdown`）。

### 工程质量

- 富文本索引走双管道：Rust 提取 TipTap JSON 纯文本，富文本笔记进入全文搜索、标签与双链索引。
- 新增斜杠命令过滤、标签/双链 mark 等纯函数测试，工作区标签跳转状态覆盖用例。
