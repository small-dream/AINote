## v0.22.0 — 2026-09-04

- 软渲染表格升级为可编辑表格：单击单元格直接编辑，Enter 向下、Tab 向右提交并继续编辑；失焦自动保存源码。

### Markdown 诊断

- 编辑器新增 Markdown 诊断入口：未闭合代码块、无效表格（缺分隔行 / 列数不一致）、frontmatter 校验（未闭合 / YAML 语法错误 / 非键值对）、图片缺地址与仓库内图片断链（新命令 `asset_exists` 批量校验）。
- 问题计数徽标 + 问题列表，点击条目跳到对应行。

### Wiki 双链增强

- 引用（出链）面板对未创建目标提供「创建笔记」一键创建，生成后即时解析为可跳转链接。
- 反向链接上下文增强：`wiki_index` 按行返回全部双链上下文（含行号，单目标上限 20 条），反链按笔记聚合展示多条带 `L{行号}` 的引用摘要。

### 启动性能

- KaTeX 改为按需懒加载（含样式与字体，仅出现数学公式时拉取），主 CSS 不再携带 KaTeX 样式；入口继续不静态依赖 Mermaid / lowlight / TipTap。

### 端到端测试

- 新增 Playwright E2E（`pnpm test:e2e`）：浏览器内以 dev-only IPC mock 驱动真实前端，覆盖切换笔记、自动保存、历史恢复、冲突恢复、图片加载与分栏滚动同步。

## v0.10.0 — 2026-09-01

### Markdown 软渲染（WYSIWYG）

- Markdown 编辑默认启用 CodeMirror 软渲染（Typora 式所见即所得）：标题（ATX 与 Setext）、加粗/斜体/删除线、行内代码、围栏代码块（语法高亮）、引用/Callout、列表与任务勾选、链接/双链、图片、表格、分割线、数学公式（KaTeX）与 Mermaid 图表直接在编辑区渲染。
- 光标或选区命中的元素淡显原始标记以便就地编辑；点击已渲染的代码块/表格/图片等 widget 会自动进入源码编辑，任务项支持点击或空格键切换勾选。
- `Ctrl+/`（macOS 为 `⌘/`）或工具栏按钮在「软渲染 / 源码」间切换，偏好按笔记持久化，默认软渲染；源码 100% 原样保存与提交，Git 保真、全文搜索与 wiki 索引不受影响。
- 新增外部链接点击打开能力（仅允许 http/https 协议），链接/双链可在编辑区直接点击。
- 性能优化：保护区改为有序区间索引 + 二分查询，5000 行密集双链文档单次重算约 5ms，无明显卡顿。

## v0.6.0 — 2026-09-01

### 真富文本编辑（.ainote）

- 新增「真富文本」笔记类型：新建时可选 Markdown / 富文本，富文本以 TipTap JSON（`.ainote`）存储并走 Git 版本化。
- 富文本所见即所得编辑器：标题、加粗、斜体、删除线、行内代码、引用、无序/有序/任务列表、代码块、分割线。

- `[[双链]]` 与 `#标签` 可视化 mark，渲染为可点击元素：双链跳转目标笔记，标签跳转侧边栏标签索引。
- 斜杠命令 `/`：输入弹出命令菜单，支持标题/列表/任务/引用/代码块/表格/分割线/行内格式，键盘上下选择、回车执行。
- 选中文本气泡菜单：块级与行级格式一键切换。
- Markdown 互转导出：富文本内容可复制为 Markdown / 粘贴 Markdown 导入（`tiptap-markdown`）。
