# 更新日志

## v0.41.0 — 2026-09-16（新增：桌面端主动升级提示）

### 新增

- **桌面端主动升级提示**：应用启动后自动检查 GitHub Releases，发现新版本时主动弹出升级提示，不再需要用户手动进入「设置 → 软件更新」。弹窗给出当前版本 → 新版本的对比与发布说明，支持「立即更新 / 稍后再说 / 忽略此版本」——「忽略此版本」按版本持久化不再打扰，「稍后再说」仅本次会话生效；下载过程显示实时进度，安装完成后自动重启。
- **设置页与弹窗共享更新状态**：设置页「软件更新」与升级弹窗共用同一份状态，手动检查、下载进度与安装失败入口保持一致，避免重复请求与状态分叉。

### 测试

- 新增桌面更新 store 单测与升级弹窗组件测试（自动检查触发、稍后再说、忽略持久化、已忽略版本不再弹、下载进度、安装失败重试）。

## v0.40.0 — 2026-09-16（新增：加密笔记 E1-E5）

### 新增

- **加密笔记全链路落地（E1-E5）**：仓库可整体启用加密笔记，正文在 Git 远端不可读——GitHub 网页、第三方 Git 客户端、拿到仓库的协作者都只能看到信封文本，文件名、目录结构与提交元数据保持明文。加密采用「信封加密」：Argon2id 口令派生 + AES-256-SIV 确定性加密正文 + GCM 封装主密钥；相同明文产出相同密文，Git 的增量压缩与行级 diff 依然有效。
- **逐篇开关**：每篇笔记可单独启用/停用加密，明文与加密笔记可在同一仓库共存；加密设置页集中管理口令、逐篇状态与强度校验。
- **会话解锁**：VaultKey 只存活在进程内存，应用退出/重启后必须重新输入口令，桌面端不提供「记住口令」；锁定态下任何命令都读不到明文，锁定后编辑器与阅读视图显示遮罩。
- **加密笔记冲突走「二选一」**：同步冲突时不再进入三栏合并，改为明确选择保留本地或远端版本，杜绝明文静默覆盖密文。

### 取舍与降级（产品决策）

- **加密笔记不提供 AI 能力**：AI 写作、问答与全库检索均不含加密笔记，右键菜单不渲染 AI 项，切换到加密笔记时自动关闭问答面板，Rust 侧二次拦截。
- **加密笔记不提供版本历史**：Diff 与「恢复此版本」对加密笔记整体不可用（`VAULT_9003`），包含删除/重命名后经 Git 历史恢复的旁路。

### 优化

- **vault.json 四步持久化**：写入改为 write → sync → rename → 目录 fsync，并在不支持覆盖的平台退化为 .bak 备份替换，修复 Windows 上修改口令必失败的问题。
- **解锁后编辑器正确重装载**：修复解锁后编辑器空白、输入覆盖原正文的数据丢失路径；加密笔记相关写入路径统一收口到 note_content，读取点（搜索、双链、AI 上下文、标题回退）全部排除信封。

### 测试

- 新增 37 个 Rust 单元测试（含跨模块 drill 演练）与 vault-flow 端到端用例，覆盖逐篇加密、锁定遮罩、解锁重装载、解密恢复明文、加密笔记冲突二选一。

## v0.39.0 — 2026-09-16（新增：待办提醒桌面端提示 + 移动端富通知）

### 新增

- **桌面端待办提醒有提示了**：桌面壳不再依赖系统预约调度（通知插件的 `schedule` 只在移动端生效，之前的桌面「未来提醒」因此形同虚设），改为应用内定时器在提醒时刻发出即时系统通知，并在窗口顶部弹出应用内提醒卡片——卡片给出任务名、截止时间、优先级与说明摘要，可直接「查看任务」（回到待办并定位到该任务）、「标记完成」或「稍后 10 分钟」；窗口没有聚焦时同时弹跳 Dock 图标，避免错过。
- **手机端通知不再是干巴巴一行**：通知标题带任务名（已过截止时刻时改为「已逾期」），正文带截止时间与优先级，任务说明摘要在 Android 展开通知时单独显示（iOS 没有 big text 样式，并入正文第二行），多条同时到期合并成一条摘要并逐条列出，通知同时带上任务 id 便于回到具体任务。应用内提醒卡片在移动壳同样可用：应用在前台时不再只能指望系统横幅。

### 优化

- **启动补发不再打扰**：只补发 24 小时内到期的提醒，更早的逾期任务仍留在待办「已逾期」分组里；同一次提醒在一个会话内只提醒一次。
- **系统通知权限请求时机后移**：只在通知真要发出的那一刻才请求权限；被拒绝时只是不发系统通知，应用内提醒卡片照常显示，待办功能不受影响。

## v0.38.0 — 2026-09-16（新增：关闭按钮最小化到系统托盘）

### 新增

- **关闭窗口改为最小化到系统托盘**：点关闭按钮不再退出应用，而是把主窗口收进系统托盘——进程、编辑状态与自动保存计时都保留，左键托盘图标或菜单「显示主窗口」即可回到原来的工作现场；macOS 点击 Dock 图标同样能把窗口叫回来。
- **托盘菜单「退出 AINote」**：真正退出改由托盘菜单显式触发，退出前依旧会确认未提交的版本与未落盘的草稿，确认后先保存草稿再退出。

### 优化

- **托盘不可用时自动降级**：个别 Linux 桌面环境没有托盘宿主，此时关闭按钮退回原来的行为——有未提交变更先确认，再关闭窗口退出，不会出现「窗口藏起来却找不回来」。

## v0.37.0 — 2026-09-16（新增：移动端系统日期与时间选择器）

### 新增

- **移动端改用系统日期 / 时间选择器**：手机上的「截止时间」「时间」chip 不再打开自研浮层，改为直接弹出系统自带控件（Android 系统日期对话框与时钟表盘、iOS 原生日期时间选择器），一次点击就能开始选择。取值口径与桌面完全一致（`YYYY-MM-DD` / `HH:mm`），改日期时保留已选时刻，系统或 chip 上的 × 都能清空回「未设置 / 当天结束前」。桌面端不受影响，仍是自研月历与时间滚轮。

### 优化

- **移动端 chip 不再弹出悬浮提示**：触屏点按会被焦点状态误触发，移动端改由 chip 自身的激活色与禁用透明度表达状态，桌面提示不变。

## v0.36.1 — 2026-09-16（优化：任务卡片版式统一）

### 优化

- **待办卡片版式统一**：新建弹窗、行内编辑器与桌面主区详情改用同一张任务卡片，标题与详情连续成一块，截止时间 / 时间 / 优先级 / 提醒四个 chip 收在卡片底部的分隔线之下、紧邻底部操作栏，属性在提交前一眼可查；删除入口固定在这一行右端。桌面仍保持「左任务流 + 右详情」并置布局，点击任务不会弹出遮罩挡住列表。

## v0.36.0 — 2026-09-15（重构：待办输入体系）

### 新增

- **截止时间可精确到分钟**：截止时间支持「只到天」与「到分钟」两种精度，前者表示当天结束前，后者按具体时刻判定逾期（今天 18:00 的任务在 18:00 之后落入「已逾期」）。标题里也能直接写「明天 18:00」「9月20日 9点30分」，只写时刻时按今天算、已过点顺延到明天。
- **提醒支持相对提前量**：提醒不再只有一个时间输入框，改为「准时 / 5 分钟前 / 15 分钟前 / 30 分钟前 / 1 小时前 / 1 天前」的提前量选项，另可精调到截止日当天的任意钟点。修改截止时间时，相对型提醒会按同一提前量自动迁移，自定义钟点保持不变。

### 优化

- **去掉清单分层**：所有任务汇入同一条任务流，按逾期 / 今天 / 未来 / 无日期 / 已完成自动分组，记待办不再需要先建容器。旧数据中的清单字段在读取时自动忽略，任务本身完整保留。
- **新建任务改为弹窗**：标题框打开即聚焦、Enter 直接创建，日期 / 时间 / 优先级 / 提醒在同一张卡片里一次设完，列表顶部不再常驻输入框。
- **日期与时间分两次设置**：日期用「快捷日期 + 月历网格」选择（周一起始、可翻月、今日描边、选中填充），时间用两列滚动选择器（顶部显示当前值，底部「现在 / 确定」）。
- **移动端触控适配**：日历格子提升到 40px、时间列表项 36px、chips 与圆形按钮不小于 36px；桌面端保持原有紧凑尺寸。

### 修复

- **未完成任务误显示完成勾**：对勾只在完成态渲染，未完成时是空心圆。
- **Escape 连带关闭弹窗**：弹窗内浮层打开时，Esc 与遮罩点击先收起浮层，不再顺手关掉整个弹窗导致草稿丢失。
- **矮视口下面板越界**：面板限高后内部滚动容器会让高度判断失真，导致浮层溢出屏幕顶部；现在按未限高时的实测高度缓存定位，顶部值与确定按钮吸顶/吸底始终可达。
- **图标提示不再被面板边缘裁切**：沿用 Tooltip 的边缘对齐模式。

## v0.29.3 — 2026-09-14（修复：软渲染行尾光标偏小点、行尾输入丢样式）

### 修复

- **行尾光标不再被截成小点**：行内标记（`**`、`*`、`~~`、反引号、转义反斜杠）此前用「1px 字号的透明字符」隐藏，CodeMirror 画光标时取的正是这 1px 盒子，于是光标停在标记上时只剩一个小点。现改为装饰替换（DOM 里零占位），光标几何取自相邻可见正文；实测 45–49 全部位置的光标高度恢复为 18px，顺带消除了那段 1px 不可点的隐形带。
- **行尾继续输入保持加粗等行内样式**：WebKit（macOS 桌面壳内核）的 `caretRangeFromPoint` 会把「可见文字右侧」的点击映射到源码行尾（隐藏标记之后），使光标跳出加粗、输入变普通文本；Chromium 则停在标记之前。现统一改用 CodeMirror 自身的坐标映射，两个内核行为一致：点在可见文字右侧（含行尾空白）都停在最后一个可见字之后，输入继续沿用该处样式；`End`/`Home` 同样停在样式内。
- **工具栏加粗不再产生空标记残渣**：光标已在加粗内（按钮为高亮态）时点击「加粗」，此前会插入一对空标记，输入后留下 `新****` 残渣；现按高亮态语义取消该格式。`斜体/删除线/行内代码` 一并生效，快捷键 `⌘B/⌘I/⌘E/⌘⇧X` 行为一致。
- 源码保真不变：渲染层只做装饰替换，笔记文件内容与 Git 提交仍是 100% 原始 Markdown（`***粗斜体***`、`**粗 *斜* 体**`、链接、双链等嵌套写法实测渲染与源码均正确）。

## v0.29.2 — 2026-09-13（修复：单仓库不再占用侧栏顶部的仓库标识行）

- 同步失败不再统一报「未知错误」：按「网络异常 / 凭证失效 / 远端拒绝」分类，并给出可操作提示——网络问题建议检查网络后重试，凭证失效引导重新登录 GitHub，权限不足提示检查仓库权限或先拉取远端更新。新增错误码 `SYNC_4002` / `SYNC_4003` / `SYNC_4004`。
- 同步失败界面收口：桌面与移动都会出现失败横幅，写明「失败阶段（本地提交 / 拉取·推送 / 推送）+ 原始原因 + 下一步建议」，并带「重试同步」与「导出诊断包」按钮；凭证失效时主按钮换成「重新登录」并直达设置页账户分区。同步失败的导航按钮在桌面转为危险色并显示「同步失败」，不再只有悬停才看得到。
- 笔记保存失败时在工具条就地给出「原因 + 建议 + 重试保存」，磁盘 / 权限类错误会提示检查磁盘空间与目录权限，其余提示重试或到「设置 → 诊断与反馈」导出诊断包；未保存内容保持 dirty，编辑区内容不会被替换。
- 删除确认框新增恢复入口：明确「删除后可在回收站恢复」并提供「打开回收站」直达按钮。

- 拉取失败会自动重试：只对幂等的拉取阶段做指数退避（3 次、0.5s 起、8s 封顶、±25% 抖动），只重试网络类错误，凭证失效 / 远端拒绝仍立即提示；推送绝不自动重试，拉取没成功也不会推送。
- 重试期间顶部显示「重试中（n/m）」与预计等待秒数，可随时「取消重试」；取消后保留原始错误与「重试同步」按钮，由你决定何时再试。启动同步、手动同步、命令面板同步共用同一份重试态。

- 同步失败现在能定位到具体阶段与文件：后端按「本地提交 / 拉取 / 推送」归因，并把相关文件（如拉取冲突的文件）随错误一起下发；失败横幅新增「失败文件」列表，超过 5 条折叠为计数，桌面与移动一致。建议文案优先采用后端给出的结论（重新登录 / 检查权限 / 解决冲突 / 重试），缺失时才按错误码推断。

## v0.10.0 — 2026-09-01

### Markdown 软渲染（WYSIWYG）

- Markdown 编辑默认启用 CodeMirror 软渲染（Typora 式所见即所得）：标题（ATX 与 Setext）、加粗/斜体/删除线、行内代码、围栏代码块（语法高亮）、引用/Callout、列表与任务勾选、链接/双链、图片、表格、分割线、数学公式（KaTeX）与 Mermaid 图表直接在编辑区渲染。

- 新增外部链接点击打开能力（仅允许 http/https 协议），链接/双链可在编辑区直接点击。
- 性能优化：保护区改为有序区间索引 + 二分查询，5000 行密集双链文档单次重算约 5ms，无明显卡顿。
